The system

A working memory layer, not a chat transcript archive.

PersonalPedia is a working system I use to preserve context across projects and conversations. The system decides what kind of knowledge a note represents, how it links to existing material, and how later agents should retrieve it.

  • Seven MCP tools covering index, read, write, search, query, ingest, and maintenance.
  • Typed pages prevent source material from being confused with interpretation.
  • Local-first Markdown keeps the corpus portable, inspectable, and versionable.
  • Operating instructions make ingestion and maintenance repeatable across agents.

The reusable framework is public. The 71-page personal instance remains private; its scale is reported without exposing its contents.

Evidence boundary: the public framework has no automated test suite or retrieval benchmark yet, so it is presented as an experiment rather than a flagship system.

Framework and instance

PersonalPedia separates the reusable system from a particular knowledge base. The public framework contains the MCP server, schema, templates, example wiki, and operating protocol; a personal instance can remain local while using the same tools.
