# Abinash Karki Portfolio Site

Canonical static portfolio for the GitHub Pages site, rewritten around inspectable evidence for Forward Deployed AI roles.

## Run

```bash
cd /path/to/Abinash-Blog
python3 -m http.server 8788
```

Open `http://127.0.0.1:8788/portfolio/`.

## Structure

- `index.html` — overview and flagship work.
- `work/tribebills.html` — product engineering case study.
- `work/nepal-energy-transparentgov.html` — civic knowledge infrastructure case study.
- `work/cross-modal-representations.html` — independent ML research case study.
- `work/personalpedia.html` — supporting agent-systems case study.
- `writing.html` — index of published essays and current writing directions.
- `about.html` — biography, working principles, and current direction.
